What's already there (TF-IDF RAG)
Every time you send a message, orchestrator.py calls memory.retrieve(query), which runs TF-IDF cosine similarity across all stored LTM entries and injects the top-5 most relevant chunks into the Claude prompt before the LLM sees your message. This is RAG — retrieve then augment then generate. The write path (store → embed → index) runs every time you call store_memory(), and the read path (embed query → search → inject) runs on every single turn.
The relevant code locations are memory.py → VectorStore (the index), memory.py → retrieve() (the search), memory.py → store_memory() (the write), and orchestrator.py → _format_retrieved() (the injection).

The one limitation — TF-IDF vs neural
TF-IDF only matches on keyword overlap. If you store "Alice is on leave" and ask "who is unavailable next week?", TF-IDF scores that as zero similarity because no words overlap. A neural embedding model understands that "on leave" and "unavailable" mean the same thing.

pythonfrom sentence_transformers import SentenceTransformer
import numpy as np

class VectorStore:
    """Neural embedding vector store — drop-in replacement for TF-IDF."""

    def __init__(self, model_name: str = "all-MiniLM-L6-v2"):
        # Downloads 90MB model on first run, cached locally after
        self.model = SentenceTransformer(model_name)
        self._embeddings: list[np.ndarray] = []
        self._meta: list[dict] = []

    def add(self, text: str, meta: dict) -> None:
        vector = self.model.encode(text, convert_to_numpy=True)
        self._embeddings.append(vector)
        self._meta.append(meta)

    def search(self, query: str, top_k: int = 5) -> list[dict]:
        if not self._embeddings:
            return []
        q_vec = self.model.encode(query, convert_to_numpy=True)
        matrix = np.stack(self._embeddings)
        scores = matrix @ q_vec / (
            np.linalg.norm(matrix, axis=1) * np.linalg.norm(q_vec) + 1e-9
        )
        top_indices = np.argsort(scores)[::-1][:top_k]
        return [
            {**self._meta[i], "score": float(scores[i])}
            for i in top_indices if scores[i] > 0.1
        ]

    def size(self) -> int:
        return len(self._embeddings)
Nothing else in the codebase needs to change — store_memory(), retrieve(), the orchestrator, the agents, and all 19 tests continue to work exactly as before because the interface (add, search, size) is identical. One improvement worth making — the current version truncates every chunk to 120 characters and drops the similarity score. Here's an enhanced version that includes the score, full content, and timestamp:
pythondef _format_retrieved(self, retrieved: list[dict]) -> str:
    if not retrieved:
        return ""
    lines = []
    for item in retrieved:
        category = item.get("category", "?")
        content  = item.get("content", "")
        score    = item.get("score", 0)
        ts       = item.get("timestamp", "")[:10]   # date only
        score_str = f" [{score:.2f}]" if score else ""
        date_str  = f" ({ts})" if ts else ""
        lines.append(f"[{category}{score_str}{date_str}] {content}")
    return "\n".join(lines)
This gives Claude richer context — it can see how relevant each memory is (score) and how old it is (date), and can weigh them accordingly when answering.
